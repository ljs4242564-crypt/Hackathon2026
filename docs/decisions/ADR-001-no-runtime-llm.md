# ADR-001: 런타임 LLM을 사용하지 않는다

- 상태: 승인
- 날짜: 2026-09-26

## 결정

`main` 브랜치의 질문 분류, 검색 순위, 추출, 답변 생성에 GPT, Solar, Gemini, Claude 등 LLM API를 사용하지 않는다. 키워드·정규식·점수·템플릿 규칙을 사용한다.

## 이유

공식 원문 확인 여부를 결정적으로 재현할 수 있고 API 비용·키·외부 모델 장애·환각 위험을 제거한다. 해커톤 시연에서 같은 입력에 안정적인 결과를 낸다.

## 결과

표현 다양성 대응에는 한계가 있으나 테스트 가능한 규칙으로 개선한다. Solar Pro 4 비교는 제출 후 별도 실험 브랜치에서만 수행한다.
