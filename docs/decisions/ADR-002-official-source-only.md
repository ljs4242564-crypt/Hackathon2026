# ADR-002: 국립순천대학교 공식 출처만 사용한다

- 상태: 승인
- 날짜: 2026-09-26

## 결정

답변 근거는 코드에 등록되고 Allowlist를 통과한 국립순천대학교 공식 URL로 제한한다. 사용자 입력 URL과 비공식 검색 결과는 Fetch하지 않는다.

## 이유

학교 정보의 최신성·책임 소재를 출처 링크로 확인할 수 있고 SSRF 및 허위 정보 위험을 줄인다.

## 결과

공식 사이트 장애나 지원하지 않는 문서 형식에서는 답변 범위가 줄어든다. 이 경우 검증 스냅샷 또는 명시적 unavailable 상태를 사용하며 추측하지 않는다.
