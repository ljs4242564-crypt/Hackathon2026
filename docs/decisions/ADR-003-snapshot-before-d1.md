# ADR-003: 제출 전 정적 스냅샷을 우선한다

- 상태: 승인
- 날짜: 2026-09-26

## 결정

제출 전에는 D1을 생성하지 않고 `SnapshotRepository` 계약과 정적 구현체를 사용한다. 스냅샷은 공식 URL에서 실제 확인한 최소 사실만 포함한다.

## 이유

인프라 변경과 마이그레이션 위험을 줄이면서 공식 사이트 장애 시연을 결정적으로 지원한다. 인터페이스를 분리해 이후 D1로 교체할 수 있다.

## 결과

갱신은 코드 변경과 재배포가 필요하다. 만료일과 확인일을 UI에 표시하고, 제출 후 D1·변경 감지·stale-while-revalidate를 검토한다.
