# ADR-004: HWP 자동 추출은 MVP 범위에서 제외한다

- 상태: 승인
- 날짜: 2026-09-26

## 결정

제출 전 MVP는 HTML과 기존 학사일정 JSON만 처리한다. HWP/HWPX, 이미지 공지와 범용 PDF 추출은 구현하지 않는다.

## 이유

Worker 번들·CPU 제한, 파서 보안, ZIP/XML 폭탄, 낮은 검증 가능성에 비해 대표 질문 안정화 우선순위가 높다.

## 결과

해당 형식에만 있는 정보는 원문 링크와 자동 확인 불가 상태를 제공한다. 제출 후 HWPX ZIP/XML과 텍스트 PDF POC를 별도 측정한다.
