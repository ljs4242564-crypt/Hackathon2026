# 1분 데모와 백업 촬영

상태: 대본 준비, 실제 영상 미완료. 실제 데스크톱/모바일 결과 화면 미완료. 로컬 Node Worker JSON은 verification/final-review/demo-results.json에 있다. 이 JSON은 upstream 502 fixture이며 실제 학교 장애나 Cloudflare 실행의 증거가 아니다.

| 구간 | 클릭/질문 | 화면에서 보여줄 내용 |
|---|---|---|
| 0–8초 | 앱 열기 | 학생 프로토타입 소개 |
| 8–20초 | 이번 학기 중간고사 언제야? | 결과, 공식 출처, 확인 방식·확인일 |
| 20–32초 | 도서관은 주말에도 운영해? | 시설별 안내, snapshot이면 명시 |
| 32–42초 | 국가장학금 신청 기간 알려줘. | 2차 종료 정보와 stale 경고 |
| 42–52초 | 도서관 평일 운영시간 알려줘 | 주말 snapshot 오답이 없음을 확인 |
| 52–60초 | 학생증 처음 발급받는 방법 알려줘 | 재발급 오답 차단, 한계 설명 |

## 별도 결과 화면 목록

- [ ] 중간고사
- [ ] 국가장학금
- [ ] 도서관 주말
- [ ] 학생증 재발급
- [ ] 학사 문의 전화번호
- [ ] 도서관 평일 오매칭 방지
- [ ] 국가장학금 1차 오매칭 방지
- [ ] /api/health JSON의 commitSha/releaseId/builtAt
- [ ] 390px에서 결과·출처·경고 잘림 없음
- [ ] 1분 MP4 파일 재생 확인

촬영 때 실제 live/snapshot/stale을 그대로 설명한다. 장애 강제 주입 API를 공개하지 않는다. 라이브가 실패하면 로컬 fixture JSON을 '모사 검증'으로 명시해 보조 설명할 수 있으나 공개 앱 필수 요건을 대체하지 않는다.
