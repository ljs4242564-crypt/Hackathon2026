# 3분 발표 대본

**0:00–0:30 문제와 대상**
안녕하세요. 화학공학을 전공하는 이재성입니다. 학교 정보를 찾다 보면 학사일정, 장학금 공지, 도서관 안내를 각각 찾아야 합니다. 저는 학생이 질문하면 공식 출처와 확인 상태를 함께 볼 수 있는 SCNU Campus Assistant를 만들었습니다.

**0:30–1:00 설계**
이 앱은 실행할 때 생성형 AI에 답을 맡기지 않습니다. 질문을 규칙으로 분석하고 학교 공식 페이지에서 근거를 찾습니다. 응답이 늦거나 실패하면 질문에 정확히 맞는 사전 자료만 표시합니다. 자료가 오래되면 경고를 표시하고 근거가 없으면 확인할 수 없다고 답합니다.

**1:00–1:40 시연**
[검증한 공개 앱 또는 명확히 표시한 로컬 결과를 사용] 중간고사 질문에서 출처와 확인일을 봅니다. 도서관 주말 질문에서는 시설별 운영 차이를 표시합니다. 국가장학금 자료는 2차의 이미 종료된 기간임을 보여줍니다. 평일 질문에 주말 자료를 쓰지 않고, 1차 질문에 2차 일정을 답하지 않는 것도 확인합니다.

**1:40–2:20 실패와 수정**
처음에는 같은 카테고리이면 비슷한 자료를 반환하는 문제가 있었습니다. 평일·주말, 최초 발급·재발급, 학기와 신청 차수를 추가로 검사했습니다. HTTP 200도 정확한 답변을 보장하지 않아 문장과 구조화 필드, 출처까지 검증했습니다. 새 재현 테스트는 수정 전 8개가 실패했고 최종 전체 146개가 통과했습니다. 정상 무결과를 연결 장애로 표시하던 상태도 고쳤습니다.

**2:20–3:00 한계와 공유**
생성형 AI는 코딩과 테스트 작성에 활용했습니다. 실제 공식 서버의 일정 조회는 이 환경에서 시간 초과였으며 이를 성공으로 기록하지 않았습니다. 오래된 정보와 파싱 한계도 남아 있습니다. 코드는 MIT 라이선스로 공유하고, 실패를 재현하는 테스트와 문제 해결 기록을 함께 제공합니다. [실제로 배포·등록한 경우에만 최종 URL과 완료 사실을 말합니다.] 감사합니다.
