# 갤러리 제출 초안 — 아직 등록하지 않음

- 프로젝트명: SCNU Campus Assistant
- 참가자: 이재성 / 개인 참가 / 기초 트랙
- 공개 앱 URL: 미확정 — 실제 Cloudflare 배포 및 검증 후 입력
- 공개 GitHub: https://github.com/ljs4242564-crypt/SCNU_OSS_HACK — 이번 수정 반영 후 사용
- 라이선스: MIT

## 소개

학교생활 정보를 찾기 위해 여러 공지와 안내 페이지를 오가는 국립순천대학교 학생을 위한 정보 안내 프로토타입입니다. 학사일정, 국가장학금, 도서관 주말 이용, 학생증 재발급, 학사 연락처를 질문하면 공식 출처와 확인 상태를 함께 보여줍니다.

공식 사이트가 느리거나 응답하지 않을 때에는 질문 범위가 정확히 일치하는 기존 확인 자료만 사용합니다. 오래된 자료에는 경고를 표시하고, 평일과 주말·신청 차수·학기·최초 발급과 재발급을 혼동하지 않도록 검증합니다. 근거가 없으면 추측하지 않습니다.

React, Hono, TypeScript 기반이며 생성형 AI를 코드 개발과 검증에 활용했습니다. 서비스 실행 중 LLM API를 호출하지 않는 규칙 기반 앱입니다. 학교 공식 서비스는 아니며 PDF/HWP 자동 분석과 모든 학교 질문을 지원하지 않습니다.

## 등록 순서

https://gallery.scnuoss.net/register.html 접속 → 필요한 로그인/참가 정보 확인 → 위 내용과 실제 공개 앱·소스 URL 입력 → 저장 → 등록 페이지를 비로그인 상태로 확인 → 등록 URL과 확인 화면 기록.
현재 갤러리 공개 안내와 교육 PDF 모두 2026-09-27 22:00 마감이며 19:00은 내부 목표였다. 등록 UI의 필수 항목이 추가로 요구되면 실제 값을 확인하여 입력한다. 미확정 URL인 상태로 제출하지 않는다.
