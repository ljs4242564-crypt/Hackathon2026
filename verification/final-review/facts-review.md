# 공식 사실 재확인

실제 HTTP 조회와 테스트 fixture는 분리한다. network.json은 공식 페이지 및 기존 공개 앱을 읽기 전용으로 확인한 결과다. HTTP 200만으로 사실 확인 완료로 간주하지 않는다.

| snapshot | 이번 확인 | 처리 |
|---|---|---|
| 중간시험 | 학사 페이지 HTML 200, 동적 일정 원문 live test timeout | 날짜 미갱신, 기존 확인 기록임을 명시 |
| 국가장학금 2차 | 공식 게시물 본문에서 2026 2학기 2차, 8/12 09시~9/9 18시 확인 | 기존 사실 유지, 종료·stale 유지 |
| 도서관 주말 | 동적 앱 셸 200, 시설 운영 본문 재확인 못함 | 평일 보장 제거, 기존 확인일 유지 |
| 학생증 재발급 | URL 200이나 수수료·절차 본문 추출/재확인 못함 | 기존 오래된 자료와 stale 유지 |
| 학사 연락처 | 공식 조직도에서 3032/3033/3035/3036의 업무 대응 확인 | 기존 사실 유지 |

어느 verifiedAt도 오늘로 바꾸지 않았다. 위에서 확인하지 못한 사실은 최신 사실로 보장하지 않는다. 해당 대표 질문은 기존 snapshot 동작을 시연하는 범위로 제한한다.
갤러리 공개 안내에서 9.27 오후 10시와 register.html 링크를 확인했다. gallery-source.txt 참조.
